# Amasty MegaMenu

This integration module fixes Amasty MegaMenu compatibility with Luma Theme + Breeze module.

**It doens't integrates Amasty MegaMenu with Breeze Themes.**

If you need MegaMenu for Breeze Themes, please consider using
[Swissup_NavigationPro](https://swissuplabs.com/magento-2-navigation-pro-extension.html)
module.

## Installation

```bash
composer require swissup/module-breeze-amasty-mega-menu
bin/magento module:enable Swissup_BreezeAmastyMegaMenu
```
